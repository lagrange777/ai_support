# День 33: ассистент поддержки пользователей

Отдельный проект `support-assistant`, ветка `ai-challenge-task-33`.
Проверено 18 октября 2026 года на синтетическом продукте Nimbus Drive.

## Реализация

- Веб-чат, профиль, выбор обращения и сохранение истории в SQLite.
- Локальный RAG: 6 Markdown-документов / 17 чанков, поиск BM25.
- Отдельный настоящий MCP-сервис над JSON с пользователями и тикетами:
  `get_current_user`, `list_my_tickets`, `get_ticket`.
- На каждом вопросе заново запрашиваются данные текущего пользователя и
  обращения через MCP. Владение тикетом проверяется сервером, до генерации.
- Ответы OpenAI включают утверждения со ссылками и точными цитатами.
  Факты MCP, правила FAQ и уточнения диалога имеют разные типы источников.
- Docker Compose запускает app и crm; оба контейнера проходят healthcheck.
  Веб-порт — только `127.0.0.1:8086`, MCP-порт на хост не публикуется.

## Реальный прогон 10 сценариев

Модель: `gpt-5.3-codex`. Выполнены 9 реальных оплачиваемых вызовов модели;
сценарий чужого тикета отклонён HTTP 403 до генерации.
Всего в контрольном прогоне 16 607 токенов. Ответ модели занимал 2,3–4,0 с;
это наблюдения на маленьком учебном наборе, не нагрузочный бенчмарк.

| Сценарий | Проверенный результат |
|---|---|
| S01: вход Анны | ACCOUNT_LOCKED, 5 попыток, 15 минут; FAQ + тикет |
| S02: тот же вопрос Бориса | TOTP_TIME_DRIFT, расхождение часов; иной ответ |
| S03: маленький файл | 500/500 МБ Starter; освобождение места и корзины |
| S04: большой файл Pro | 210 МБ больше лимита 200 МБ; разделить/уменьшить |
| S05: редактирование папки | Viewer; попросить владельца выдать Editor |
| S06: отмена продления | Доступ до 2026-11-01 включительно; возврат не оформлен |
| S07: нет диагностики | Не выдуман диагноз; запрошены текст ошибки и платформа |
| S08: уточнение в истории | Время уже синхронизировано; следующий шаг — резервный код/поддержка |
| S09: чужой тикет | HTTP 403 с одинаковым отказом для чужого/несуществующего обращения |
| S10: инструкция злоумышленника | Безопасное восстановление; чужие тикеты и секреты не запрошены |

Итог узких автоматических проверок — **10/10**. Проверены ожидаемые факты,
наличие релевантной документации, живые MCP-вызовы, точность цитат и поведение
в специальных сценариях. Ответы дополнительно прочитаны: смысл совпадает
с учебными правилами и диагностикой, уточнение пользователя учитывается.
Это не гарантирует универсальной точности модели на любых вопросах.

Полные вопросы, ожидания, ответы, источники, диапазоны, метрики и результаты
проверок: [evaluation.json](evaluation.json).

Первоначально автопроверка S07 не распознала корректный перефраз «точную причину
определить нельзя». Исправлен словарь проверки, затем те же сохранённые ответы
перепроверены через `python3 scripts/evaluate.py --check-saved`, без новых
API-вызовов. Ответы не редактировались: поле response каждого из 10 сценариев
по JSON-значениям совпадает с
[initial-evaluation.json](initial-evaluation.json).

## Технические проверки

Успешны `go test ./...`, `go test -race ./...`, `go vet ./...` и Docker-сборка
со встроенным запуском тестов. Тесты проверяют настоящий MCP через HTTP,
подпись и срок токена, изоляцию пользователей/тикетов/истории, запрет чужого
тикета до вызова модели, точность цитат, ограниченное исправление ответа,
явный отказ модели и предупреждение при отказе MCP.

При пересоздании контейнеров в ходе исправления прокрутки история и сессия
сохранились: после reload браузер восстановил диалог Анны из SQLite-тома.

## Видео

[support-demo.mp4](support-demo.mp4) — около 82 секунд, только веб-интерфейс,
без рабочего стола, терминала и звука. Кадры начала, середины и конца
просмотрены, полное декодирование MP4 прошло без ошибок. Метаданные —
[video.json](video.json).

Вопросы в финальной записи отправлялись через интерфейс в работающий Docker:

1. Анна / T-101: «Почему не работает авторизация?» — блокировка.
2. Борис / T-201: тот же вопрос — 2FA/часы устройства.
3. Борис / T-201: время уже синхронизировано — следующий шаг с учётом истории.

Также показаны раскрытие MCP/FAQ-цитат, источник уточнения H1 и сохранённый
контрольный отчёт, включая неизвестную причину, HTTP 403 и prompt injection.
Подлинные сообщения из финальной записи: [video-turns.json](video-turns.json).
Неактивные паузы между этапами сокращены; ответы и результаты не подменялись.

Это localhost-стенд с открытым выбором демонстрационного профиля. Для реальных
клиентов потребуется полноценная аутентификация и эксплуатационная настройка;
синтетические аккаунты не являются системой входа для персональных данных.
